# VETERAN – Skillsystem für Incursion Red River

Ein deutsches Skillsystem für **Incursion Red River 1.4** (UE4SS-Mod) von **itsnotabug**.
Deine Spielweise macht dich besser: Wer viel sprintet, bekommt mehr Ausdauer, wer mit Sturmgewehren trifft, beherrscht ihren Rückstoß besser – aber nur, wenn du lebend extrahierst.

## Installieren

1. ZIP irgendwohin entpacken (z. B. auf den Desktop).
2. Spiel beenden.
3. Doppelklick auf **„Veteran installieren.bat“**. Der Installer findet das Spiel über Steam.
   - Ist UE4SS schon installiert, wird es weiter benutzt – deine Einstellungen und anderen Mods bleiben unangetastet.
   - Sonst wird das mitgelieferte UE4SS 4.0.0 eingerichtet.
4. Spiel starten – im Inventar erscheint oben der Button **VETERAN**.

## Aktualisieren

Gibt es eine neue Version, zeigt der Mod im Versteck den Hinweis **„Update verfügbar“**.
Dann das Spiel beenden und **„Veteran aktualisieren.bat“** starten: Die neue Version wird von hier geladen, ihre Prüfsumme (SHA-256) kontrolliert und installiert. Dein Fortschritt bleibt erhalten.

Der Mod fragt dafür höchstens einmal am Tag bei GitHub nach der neuesten Versionsnummer. Dabei werden **keine persönlichen Daten** gesendet.
Wer das nicht möchte: eine leere Datei `kein_update_check.txt` in den Mod-Ordner legen.

## Entfernen

Doppelklick auf **„Veteran entfernen.bat“**. UE4SS wird nur entfernt, wenn es mit Veteran installiert wurde und keine anderen Mods darin liegen. Dein Fortschritt bleibt erhalten.

## Was der Mod kann

- **14 Skills** in drei Bereichen: Körper (3), Waffen (7 Gattungen), Überleben (4), jeweils Stufe 0–100
- Erfahrung zählt erst bei der **Extraction** – Tod = nichts. Mit Leih-Ausrüstung gibt es die halbe Erfahrung.
- Die **KI-Schwierigkeit** zählt mit: Rekrut ×0,75 · Regulär ×1 · Veteran ×1,25 · Elite ×1,5 (eigene Einstellungen ×0,75)
- Spürbare, aber moderate Effekte: Tragkraft, Ausdauer, Rückstoß, Anlegen, Waffenstörungen, Suchzeit, Blutung
- **13 Dienstgrade** vom Rekruten bis zum Veteranen, **25 Abzeichen** (z. B. Kopfjäger, Adlerauge, Monsterjäger, Geist), K/D-Zähler
- Ausführliche Statistik: Kopfschüsse und Kopfschuss-Quote, weitester Kill, Kills je Fraktion und Boss-Kills, Mehrfach-Kills, Schaden, durchsuchte Kisten, Strecke und vieles mehr
- Skill-Fenster mit den Reitern **Skills · Abzeichen · Statistik** über den Button VETERAN im Inventar (oder F7), unten rechts der Button **UNTERSTÜTZEN**
- Hinweise im Spielbild bei Stufenaufstieg, nach dem Raid ein **Veteran-Block im Extraktions-Bildschirm** des Spiels
- **Online-Bestenliste** auf [itsnotabug-games.com](https://www.itsnotabug-games.com/leaderboard/) – freiwillig, einmal im Reiter STATISTIK einschalten, danach gleicht sich der Mod nach jedem Raid selbst im Hintergrund ab. Der Server prüft jede Raid-Kette nach.
- Klick- und Hover-Klänge wie in den Spielmenüs
- **Deutsch und Englisch** – automatisch wie die Spielsprache, umschaltbar über die Flaggen im Skill-Fenster

## English

**Veteran** is a skill system for **Incursion Red River 1.4** (UE4SS mod) by **itsnotabug**. You get better at what you do – but only if you extract alive.

- **Download:** [latest release](https://github.com/itsnotabug-mods/veteran-mod/releases/latest) → `Veteran_v…_Komplettpaket.zip` · also on [Nexus Mods](https://www.nexusmods.com/incursionredriver/mods/371)
- **Install:** unzip anywhere, quit the game, double-click **„Veteran installieren.bat“** (finds the game via Steam, uses an existing UE4SS or sets up the included UE4SS 4.0.0). In the inventory, click **VETERAN** (or press F7).
- **Update:** when the mod shows “Update available” in the hideout, quit the game and run **„Veteran aktualisieren.bat“** (download is checked with SHA-256, your progress is kept). The mod checks GitHub at most once a day and sends no personal data.
- **Remove:** **„Veteran entfernen.bat“**.
- **Features:** 14 skills (level 0–100), experience only on extraction, AI difficulty multiplier (Recruit ×0.75 … Elite ×1.5), 13 ranks, 25 badges, detailed statistics (headshots, longest kill, kills per faction …). The mod is in **German and English** – it follows the game language; switch with the flags in the skill window. **Online leaderboard** at [itsnotabug-games.com](https://www.itsnotabug-games.com/leaderboard/) – optional, turn it on once in the STATISTICS tab, then the mod syncs in the background after every raid.
